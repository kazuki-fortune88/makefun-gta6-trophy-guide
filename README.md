Sunset Platinum — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: a checklist with saved progress, a 7-stage roadmap to platinum, the one truly missable trophy (plus the timing-sensitive ones), a Next-up planner, and a cited guide for every trophy. No network, no account, no Rockstar artwork.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 (use `--port <n>` for another port).
